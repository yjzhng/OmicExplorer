v0.5.0's installers failed to build, so 0.5.1 is the first release of everything below, plus one fix.

## Features

- **Searchable User guide**, rewritten for the current app. It covers every step and plot, and ⌘F / Ctrl+F searches it.
- **Plot settings in one order**: Statistic, then **General** (what the plot shows, label limit, max genes, legend, palettes), then Points / Lines, then Axes. Opacity can be typed as a number. Label rows read switch → colour → size, with a label size.
- **Correlation**: choose Pearson r, Spearman ρ or CCC. Each clusters on its own distance.
- **Fold-change heatmap**: coloured tracks show each column's comparison and conditions. Columns can cluster by size and pattern, or by pattern only.
- **Colour by several conditions** on QC, Bar and Cluster plots: each combination gets its own colour, with an optional numeric condition as a fade.
- **iWantHue palette**: colour-blind-safe categorical colours, as many as needed.
- **Gene selector**:
  - **Current selection** always comes first, with Save as, Edit and Clear.
  - Group edits are drafts: **Confirm** keeps them, **Cancel** puts the group back.
  - A **switch** mode highlights one group at a time.
- **Threshold lines** can be hidden or restyled under Axes and lines.
- **Reset layout** on each results tab.
- **Long lists show every row**, scrolled instead of capped: gene search, value pickers, import previews and filters, Compare and Contrast previews.

## Fixes

- **Home page version tags**: projects saved by an older version show their amber tag and **Fix** again (the check had stopped running in 0.4.2).
- **Selected points no longer disappear** after the cursor leaves a plot straight from a threshold line.
- **Tooltips** sit at the bottom right of the cursor, above the tiles, so a tile's edge no longer clips them.
- **Dose/time-response detailed view**: hovering or clicking a point selects the protein, and legend hover picks the right line.
- **Enrichment**: selecting a term highlights it and fades the others, stems included.
- **Bubble**: selected proteins join in score order instead of at the end.
- **Custom conditions** show by name, not `@name`, in ANOVA terms, previews and axis titles.
- **Contrast previews** show a Compare side's full comparison (X | Y).

## Behaviour changes

- **Point defaults**: dot size 7 / 8 / 9 (plain / significant / selected), outline 0.5 on significant and selected points, opacity 50% / 80% / 100%, and 20% for points not selected.
- **Effect colours belong to plots**: Compare no longer sets up / down colours. Projects keep their colours: they move to the plots each Compare feeds.
- **Reference-protein normalisation** now divides by the reference protein in each sample, so values are fractions of it. The protein must be measured in every sample; Clean data names the samples where it isn't. In a project from an earlier version these Clean data steps open as not run, to be run again (the home page's **Fix** saves the project that way); fold changes after them don't change.
- **Fold-change heatmap** keeps every column; "differential only" no longer drops columns with nothing significant.
- **Labels**: samples read `HeLa · dTAG · 100 · r1` and facets `dose 10`.
- **Correlation plots** from older projects need one re-run.
- **Projects saved by 0.5.0** are meant for 0.5.0 and later.
