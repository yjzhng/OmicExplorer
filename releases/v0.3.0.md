## Features

- Protein–protein interaction network (STRING): a network view builds a STRING interaction graph for a comparison's significant hits, with edge-confidence weighting and linked highlighting.
- Functional enrichment (GO / KEGG): a new enrichment node and view with ORA and GSEA, dot/ridge styles.
- External annotation, cached locally: UniProt (gene/protein/GO/organism) and KEGG pathway annotation fetched in the main process and stored in a version-stamped app cache, so repeat runs are offline-fast. Includes an essential-gene set from DEG.
- Compare across two datasets: a Compare tile now accepts two Standardize inputs, pooling conditions from both datasets (matched by shared feature ID) — e.g. to check reproducibility between replicate subsets.
- Generalized Contrast: now accepts two same-kind inputs (two Compares → FC-vs-FC, or two Standardizes → abundance-vs-abundance) joined by shared conditions, in addition to the existing single-Compare condition split.
- Dose-/time-response comparison: Contrast can plot a per-gene dose- or time-response profile across the two contrasted sides, with a categorical (evenly-spaced level) x-axis and all levels shown even when unmatched.
- Custom gene sets with visibility toggle: an eye icon hides a set; hidden genes are masked non-significant across every comparison/contrast in the project, recomputing automatically — for dropping inherently-variable genes.
- Gene stepper for single-gene plots: Contrast DR/TR, TDR, and gene-bar tiles get a "‹ n/m › gene" pager with a searchable jump-to-gene dropdown.
- PCA/Cluster controls in tile settings: per-tile settings now expose scaling (covariance vs unit-variance), missing-value handling (complete-cases vs impute), per-sample normalization, feature selection (top-variable), log transform, and individual-vs-condition-mean replicates — with a scree/diagnostic readout. Defaults now match standard proteomics-tool PCA (covariance · complete-cases · log2).
- Pick data files outside the data folder via a system file browser in the data-tile import.
- Resume where you left off: opening a project restores the last page (Workflow canvas or Results dashboard) and its active tab.

## Fixes

- PCA was silently wrong for more than ~a dozen samples: the symmetric eigensolver failed to converge on larger matrices, smearing the dominant axis across many components (e.g. a real 52%-variance group axis reported as ~4%, with samples appearing not to separate). Rewritten with a numerically stable cyclic Jacobi; PCA now recovers the correct variance structure at any sample count. Recompute existing Cluster tiles to pick up the fix.
- Creating a new workflow didn't switch to it: new workflow/folder ids collided with saved ones after reopening a project, so switching landed on the old workflow. IDs are now reserved past everything in the loaded project.
- Stray "(no path)" folder left in the folder selector after adding a data folder — the initial placeholder is filled in place, and dangling path-less folders are pruned on open.
- Drag-selecting tiles on the canvas no longer opens a node's config panel — that's now a click-only action; a marquee drag only drives multi-select.
- Network graph legibility: resting nodes are no longer over-dimmed, edges are trimmed back to node radius so they don't cross behind transparent fills, and neighbours dim when a node is focused.
- Invalid data→plot connections are rejected (the connection dot flashes red) and hidden from the add-plot menu, preventing invalid routing.
