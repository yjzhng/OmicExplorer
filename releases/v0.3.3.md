## Features

- **Form layout**: a second way to work, alongside the flow canvas (Settings → Layout). The workflow is a column of step tiles in your own order. Each tile shows its category, name, inputs/outputs, a status dot and a Run pill. Selecting a step opens its settings in the middle. Interactive dialogs (import, compare, contrast) open in a third panel on the right, via the step's Configure button. Plot steps show their sibling plots and the selected chart. Steps can be reordered by dragging, but never above one of their own inputs.
- **Clean data — Log-transform**: a histogram of the values as loaded appears straight away from the Load data step, with no run needed.
  - **Detection**: the scale (linear / log2 / log10) is detected and shown beside the histogram.
  - **Transform**: a none / log10 / log2 switch sets the output scale and previews the distribution after the transform. It defaults to log10 for linear data and none for already-logged data.
  - **Analyses unaffected**: analyses always run on the same linear values, whether the data arrived raw or logged. The transform only sets how Clean data's table and CSV present them.
- **Clean data — missing-value imputation** (optional): fills gaps left after clean-up with values drawn just below each sample's distribution, in the style of Perseus. Shift and width are adjustable, re-runs give the same values, and the panel reports how many values were imputed.
- **Clean data — "Coverage per"**: the minimum-sample-% rule can be applied within groups (e.g. per cell, or cell × dose). A gene is kept if it clears the bar in any one group.
- **Custom conditions**: samplesheet columns that group samples (beyond cell / compound / dose / time) are picked up as extra condition axes and carried through the analysis.
- **Merge step**: pools several Clean data inputs into one dataset, uniting their genes and conditions. It can be used anywhere Clean data can.
- **Rebuilt Compare dialog**:
  - **Compare on**: a switch per condition (one for a t-test, two for two-way ANOVA). Every other condition is matched like-for-like, and you choose which of its values to include.
  - **Live preview**: lists the comparisons that will run and any warnings.
  - **Several numerators**: "A, B vs C" runs A|C and B|C.
- **Inter-dataset Contrast**: a Contrast tile accepts any number of inputs. Pick dataset A (y) and B (x) and the conditions to match on, and see which values pair. Conditions that aren't matched are fixed to one slice per side, so nothing is averaged across a condition. Unused inputs are drawn as dashed edges.
- **Thresholds**:
  - **Effect size**: optional separate up/down cutoffs on Compare and Contrast.
  - **Multiple testing**: choose Benjamini–Hochberg (FDR) or Bonferroni (FWER).
  - **Snapping**: dragged cutoffs snap to round values.
  - **Effect class names**: can be renamed per Compare.
  - **Volcano**: its plot settings now include these statistic settings.
- **Plot appearance**:
  - **Volcano, MA and scatter**: per-group colour, size, opacity, labels and legend name, plus the highlight look, with a live preview.
  - **Axes**: titles, ranges and font sizes on every plot.
  - **Gene cap**: limiting a plot to its top genes is now an on/off switch with a count. The default is 20.
- **Cluster plot**:
  - **Data**: replicates or condition centroids.
  - **Territory**: convex hull, ~95% Gaussian ellipse or none.
  - **New views**: PCA loadings (the genes driving the separation) and a scree plot (variance explained per component).
  - **Quick access**: plot, colour by and territory are on the tile by default.
- **Results tiles**:
  - **Header buttons**: Copy (PNG or SVG), Download (SVG / PNG / PDF; tables as CSV / XLSX) and a settings gear with the full plot settings.
  - **Matching output**: copies and downloads match exactly what's on screen, theme included.
  - **File names**: files are named after the plot, comparison and context.
  - **Bulk export**: covers every facet, plus a selected-genes-only set when genes are selected.
- **Data tables**: comparison and contrast tables gain a gene × context Matrix view with heat colouring.
- **Gene selector**: now sits in the centre of the top bar.
  - **Tabs**: Function (e.g. COG), Pathway (e.g. KEGG) and Essentiality, each with a source picker that only lists what your data has.
  - **Label**: shows the gene set or category name when the selection matches one exactly.
  - **New gene sets**: created from the "+ New" tile, either empty or from the current selection.
  - **Editing mode**: genes are only added or removed while a set is being edited. Edit and Confirm controls and a tinted background make that mode clear.
  - **Colours**: a set can have its own point colour on volcano, MA and scatter.
- **Annotations**:
  - **GO**: fetched as Biological Process / Molecular Function / Cellular Component.
  - **COG**: categories are grouped by their NCBI functional area, as KEGG pathways are by category.
  - **Essentiality**: adds the human core-essential (CEGv2) and non-essential (NEGv1) reference sets. These can report a gene as non-essential, not just unknown, and are bundled with the app so no network is needed.
- **Enrichment**:
  - **When available**: enabled whenever any supported annotation (GO, KEGG, COG, …) is present, falling back in order when one is missing.
  - **Term selector**: lists only the available sources, under plain names ("KEGG", "COG").
  - **Groupings**: shown as a coloured square beside each term.
- **Navigation**:
  - **Switching pages**: "Results →" on the canvas and "← Workflow" on the dashboard, with a sliding page transition.
  - **Data tabs**: scroll, with the button and DATA label kept in place.
  - **Dashboard**: always editable.
- **Settings**: reorganised into Layout, Plots, Export, Appearance and About. Plots holds defaults for copy/download format and DPI.
- **Unsaved changes**: closing, opening another project or starting a new one asks Save / Don't Save / Cancel. Reopening a project returns to the page and tab you last had open.
- **Status**: a step's status dot and the plot menus reflect what the data supports, and say why when it doesn't (e.g. "Needs a dose condition in the data").
- **Canvas**: two-finger scroll pans, pinch zooms and dragging on empty space draws a selection box. A step can't be run until its upstream steps have results.
- **Toggles**: all toggle switches share one animated style, including the condition switchers.

## Fixes

- Click-to-select now works reliably on the STRING network and enrichment ridge plots, including when nothing is selected yet.
- t-SNE embeddings could blow up to huge coordinates; the optimiser is now stable and deterministic.
- Comparisons no longer treat a condition the vehicle has only one value of (e.g. DMSO only at dose 0) as a second axis.
- When one side is measured at fewer doses than the other, the comparison skips the missing doses instead of being blocked.
- Two-way ANOVA skips contrast rows present on only one side. Contrast facet tabs with data on only one side are greyed out, with a tooltip, and aren't exported as empty plots.
- The correlated-contrast prediction band was drawn with near-zero width. It now uses the correct critical t.
- Volcano/MA guide lines always match the point colours, even while a settings change is waiting for a re-run.
- Response-plot error bands no longer cut across gaps where a dose has no value.
- Numeric-looking category labels ("2.5", "10") no longer flip to numeric spacing after hover or selection.
- Hover tooltips no longer cover the point's label. Gene labels get leader lines when far from their point, and highlighting no longer flickers.
- Clicking or hovering no longer redraws every chart on the dashboard, and selecting a gene no longer lags.
- Data tables: rows render correctly under search/filter/sort, clicking a row selects the gene, and column filter menus stay open while you tick values.
- The interactive import's Re-fetch button stays on the same line as Fetch while fetching.
- Step names are limited to file-name-safe characters, as they lead downloaded file names.

## Behaviour changes

- **Standardize is now "Clean data"**.
- **The "strain" condition is now "cell"**. Old samplesheets and projects are migrated automatically.
- **The MA plot's x-axis and abundance contrasts are now on log10** (previously log2), so their numbers change.
- **The Cluster plot takes Clean data input only**.
- **Per-plot "focus" genes are gone**. Plots follow the shared gene selection via the All / Selected toggle.
