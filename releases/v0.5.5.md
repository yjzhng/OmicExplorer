## Fixes

- **PNG resolution**: downloaded PNGs record their DPI, so file properties and layout apps read 150 / 300 / 600 dpi instead of 96 (Windows) or 72 (macOS). The pixels are unchanged.
- **STRING for bacterial strains**: the network uses STRING's own organism, read from the proteins' STRING ids, where it differs from UniProt's (E. coli K-12: STRING 511145, UniProt 83333).
- **KEGG pathway names** are cleaned correctly for organisms with a hyphen in the name (E. coli K-12).
- **Heatmaps** reopen at once when you come back to Results, switch tabs or facets, instead of clustering again.

## Behaviour changes

- **Editing a group**: tiles and groups in it show as selected (green, with a tick); click one to select or deselect it.
- **Group names**: click the name to rename (was double-click).
