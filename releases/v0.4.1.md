## Features

- **In-app update**: Settings → About → Updates → **Update now** downloads the new version and installs it when the app restarts. This works from v0.4.1 onwards; on macOS, the app must be in Applications. The update check now works on networks shared by a whole institute, where GitHub's request limit used to make it fail with "Couldn't check".
- **Batch correction**: in Clean data, define batches such as merged datasets or TMT plexes, filled from a condition or from Merge's inputs and adjustable sample by sample. The correction removes each batch's offset while protecting the conditions, and refuses a design where the batches and conditions are confounded. Compare's t-test accounts for the batches, Contrast can select and group by batch, and Compare can give one fold change per batch.
- **Samplesheet import**: the interactive import's Conditions step reads a samplesheet in any layout. It matches rows to sample columns by name, maps the sheet's columns to conditions, and lets you drag a row onto a sample to match it.
- **Sample QC**: the Clean data table has a QC view listing, per sample, the counts of measured, imputed and missing values, the median and quartiles of abundance, and the median CV of its group. The view downloads as shown.
- **Copy and paste tiles**: copy selected tiles and groups (⌘C or the Copy button) and paste them (⌘V or right-click on the canvas) into any workflow, project or window. Converted Load files come along, and pasted tiles wait to be run.
- **New Window**: File → New Window (⌘N), or from the Dock icon's menu.
- **Edit a group's members**: use the pencil on a group's frame to add or take out tiles, applied with ✓ as a single undo step.
- **Load data status**: the Load tile's status flags raw data that changed or went missing since it was read. If an interactive import's raw data changes and the import still fits, it is converted again automatically. The Load tile's Run button re-converts or re-checks it.
- **Contrast**: independent comparisons use a cutoff on each axis, set like a volcano's fold-change and significance lines, instead of a per-axis Gaussian. The correlated band can have a separate lower level.
- **Gene groups**: pick several groups and combine them as a union or an intersection.
- **Label colours**: on volcano, scatter and MA plots, labels can take their own colour, by default the colour of their data group, including for selected points. Gene-group colours now also apply to dose- and time-response plots.
- **Default plots**: in Settings → Plot defaults, choose the plots a new plot tile starts with, for each kind of step (Clean data, Compare, Contrast, Curve fit…), and the order plots appear in on the results dashboard. Plots the data can't support are left out.
- **Results dashboard**: Settings → "Results dashboard: default plots per row" sets 2, 3 (the new default) or 4 plots per row.
- **Readable download names**: plots and tables download as *tab - plot - view*, for example `AU28 r3 - Volcano - AU-28 vs DMSO - 0.16 µM, 72 h`.
- **Table downloads match the screen**: a table downloads with the same columns, headers and order as shown. Comparison tables always include the comparison column, and condition columns carry their units.
- **Empty plots say so**: a plot with nothing to draw for the conditions on show says so, instead of showing empty axes.
- **Data clean-up moves files to the Bin** instead of deleting them, so anything removed by mistake can be restored.
- **Windows installer icons**: the installer and uninstaller have their own badged icons, so the setup file isn't mistaken for the app.
- **Build it yourself**: with git and Node.js, `scripts/install-from-source.sh` (macOS) or `install-from-source.ps1` (Windows) builds and installs the app from source, with no security prompt. Run it again to update.

## Fixes

- **Plot exports in Illustrator**: SVGs, volcano plots especially, no longer paste far off the artboard.
- **Selected point size** now applies to genes in a selected gene group.
- **Duplicating a plot group** keeps its results layout.
- **Saved results' scales** follow their Clean data step's log-transform setting when a workflow is opened.
- **Excel files** written by Excel itself now read correctly.
- **Running from source**: the dev launcher reinstalls dependencies after a `git pull` that changes them.
