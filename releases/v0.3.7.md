## Features

- **Project versions on the home page**: each recent project shows the app version that last saved it. The tag is amber for an older file and red for one saved by a newer app. **Fix** rewrites an older file in the current form and keeps the old one beside it as a `.bak`.
- **Project menu** on the home page: open, show in the file manager, fix, or remove from the list (the file stays on disk).
- **Settings → Database**: browse, search and filter the cached UniProt annotations by species and source.
- **Import search**: the Metadata DB step searches every kept protein and can show only proteins with no annotation.
- **Plot export**:
  - **Plot font** for on-screen plots and exports.
  - **White or transparent** export background. Exports are always drawn in light colours.
  - **Editable copies** (macOS): a copied plot pastes as vector art into Illustrator, Keynote and PowerPoint.
  - **3-D exports** at the chosen DPI, with axes, labels and lines as vectors.
- **3-D Response plot**: axis labels sit on the box, lines on surfaces no longer break up, rotation and zoom survive redraws, and a perspective/orthographic setting.
- **Curve fit settings**: choose a **Method** (Hybrid, 4PL or custom) with its **Detector** and **Descriptor**. "Responders only" description now works for 4PL too.
- **Plot defaults** has its own Settings page: pick the step, then the plot.
- **Cluster plot**: a "minimal" axes option.

## Fixes

- **UniProt fetches**: a failed request is retried, and only the failed batch is lost ("N of M proteins not fetched — fetch again"), not every uncached protein.
- **Older projects**: every workflow is brought up to date when the file is opened, not only the ones opened in the editor.

## Behaviour changes

- **Slice fits**: "time slice" and "dose slice" are now one **slices** option. The per-dose view is the Response plot's slice switch. No re-run needed.
- **4PL dose × time surfaces** reuse the detector's fit for the description, so descriptions may shift slightly after a re-run. Only R² is reported as the fit check.
- **3-D Response plots** open in orthographic view from a raised camera.
- **Projects saved or fixed by 0.3.7** are meant for 0.3.7 and later.
