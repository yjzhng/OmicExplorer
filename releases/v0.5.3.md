## Features

- **Enrichment categories keep their colour and order**: a category (GO aspect, KEGG category, …) has the same colour and legend position in every enrichment plot of a dataset.
- **Enrichment: order terms by category**: a new **order** setting stacks terms by category first, then by significance.
- **Enrichment: category palette per plot**: a **categories** row in Colours, Automatic following the global palette.
- **Enrichment term labels use the room there is**: long term names show in full in wide tiles, while the plot keeps at least 30% of the width; very narrow tiles scroll sideways instead of squeezing the plot.
- **Crowded tile switches become dropdowns**: when a switch's options don't fit on one line beside its label, they become a dropdown instead of running off the tile.

## Fixes

- **Enrichment ridge plot**: turning the legend off hides it; no empty band above the top ridge; term labels and spacing match the dot and bar plots.
- **Enrichment dot plot**: the "lead genes" key is no longer cut off at the right edge.
- **Enrichment legend** wraps only when it has to, and sits closer to the plot.

## Behaviour changes

- **In-app update in a protected Applications folder**: when your account can't change the folder OmicExplorer is in (e.g. /Applications on a managed Mac), **Update now** works and macOS asks for an administrator's password to put the update in place, instead of only offering the download.
- **iWantHue is the default categorical palette** (groups, conditions, clusters, enrichment categories). A palette you picked in Settings is kept.
- **Enrichment colour settings** read **effect palette** and **effect group**: up / down can be a fold change or an NES sign. The **none** colour is greyed unless the ridge style draws it.
