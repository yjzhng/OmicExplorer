## Features

- **ANOVA over any conditions** replaces the 2-way ANOVA: one-way, two-way or n-way, with an F-test per factor and interaction. A numeric condition (dose, time …) is a **slope** by default, or can be a **factor**. The preview warns about nested conditions and empty level combinations.
  - **New plots**: **Variance** (each factor's share of a gene's variation) and **Interaction** (cell means across one factor, a line per level of another).
- **Numeric custom conditions**: any custom condition can be numeric, with a unit, and used like dose and time: in curve fits and in Response plots. Unit boxes suggest standard spellings (`uM` → `µM`).
- **Curve fit axes**: each axis has a scale (log or linear) and a baseline, either the vehicle or the axis's own first level (e.g. thermal melts). A surface can use any pair of numeric conditions.
- **Curve metrics plot**: one gene's fit parameters as bars (EC50, slope, plateaus, R², q), per slice for a surface.
- **Response plots for every numeric condition** and every pair of them, each its own tile.
- **Clean data**:
  - **Reference protein normalisation**: shift each sample so one housekeeping protein reads the same everywhere.
  - A second Clean data step can follow another.
- **Subset**: keep chosen replicates, drop single samples, or filter the raw import before Clean data.
- **Progress bar** for curve fits.
- **Open projects from Finder or Explorer**: double-click a `.omicexplorer` file to open it in its own window. Several projects can be open at once.

## Fixes

- **One failing plot** no longer blanks the Results page: the tile shows its error and the rest still draw.
- **PDF export**: dashed lines stay editable lines in Illustrator.
- **Unsaved changes** are asked about per window.
- **Large projects** use less memory and open faster.
- **Home page**: a project is tagged older only when Fix would actually change it.

## Behaviour changes

- **Saved 2-way ANOVAs** open as the ANOVA with their factors kept as factors. P and q values change after a re-run: the test now uses the model's moderated residual variance, not a Welch t-test per comparison.
- **Dose and time axes** are no longer always log: each axis's scale follows the spacing of its levels, and is linear when it can't tell. Evenly spaced levels may now be fitted on a linear axis.
- **Curve fit defaults**: the CurveCurator fold-change cutoff is now |curve log₂FC| ≥ 0.5 (was 0.45). The dose × time surface cutoff is now non-linear, at |log₂FC| ≥ 0.5.
- **Curve fits may change after a re-run**: curves against their own first level start at 0, and vehicle drift is estimated along any numeric condition.
- **Subset**: a condition narrowed to one value is no longer an active condition, so labels drop it and plots no longer offer it as an axis.
- **Samplesheets**: a custom condition declared numeric must hold numbers.
- **Projects saved or fixed by 0.3.8** are meant for 0.3.8 and later.
