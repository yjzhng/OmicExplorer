## Features

- **Logged values shown as themselves**: with a log-transform, Clean data's new **show** setting reads either **log₂ values** or **original values on log₂ axis** (log₁₀ likewise). The second keeps the log positions and the analysis but labels axes, colour bars, hovers and tables with the plain values (0.01, 0.1, 1). Fractions of a reference protein default to it.
- **Clean-up modes**: remove proteins below the threshold overall or within each condition group, or keep proteins above it in at least one group or in every group. The threshold is a percentage or a number of samples (**%** / **#**).
- **Run a group**: a group's **Run** button runs the steps inside it; Run and Stop also work on a selection. Stale steps upstream run first. A running group shows a progress strip.
- **Duplicate a group**: copies the group with its steps and the connections between them, named `_copy`, `_copy2`, …
- **Top genes split between up and down**: heatmap, bubble, dose response and dumbbell can split their top N **proportionally**, by **absolute size**, or by a set count per side.
- **Volcano: force p-value / q-value**: genes with a fold change but no p-value (e.g. the reference protein) can be drawn at 0 on the significance axis instead of left out.
- **Interaction plot in 3-D**: a 3-D view (lines, or a surface when both factors are numeric) and a 2-D heatmap of the cell means.
- **Enrichment term modules**: terms carried by the same genes are grouped into modules, with an option to show one term per module.
- **Box and lasso selections stay on the plot**: a selection becomes a region you can move and resize; it pins the genes inside it. Shift adds another region.
- **Model formulas explain themselves**: hover a formula's function name to see its equation.

## Fixes

- **Interaction plot**: no legend when factor 2 is **none**.
- **Results tab switcher** no longer turns into a dropdown when its tabs fit.
- **Reset axes** returns to the plot's current range, not the one it was first drawn with.
- **Box / lasso outline** is visible on the light theme.

## Behaviour changes

- **Ranking section**: Max genes / terms, label limits and the other top-N settings moved to a new **Ranking** section in plot settings.
- **Compare window**: ANOVA can be chosen before or after the conditions; a design that can't hold one says why.
- **Enrichment top N is a cap**: picking categories or modules in the legend draws their top terms from every term computed, not only those shown.
- A group's Run and Edit buttons appear on hover.
