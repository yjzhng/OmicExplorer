## Features

- Contrast now defines its two sides explicitly: instead of picking one condition and two of its levels (with the join context inferred), a Contrast tile opens the **same interactive selector window as Compare** — FC1 = one cond-value selection, FC2 = the other, with explicit "match on" context and a live preview of how many genes pair per context group. Nothing about the context is guessed. (The "Pair two inputs" reproducibility mode is unchanged.)
- Interactive import — per-row condition painting: sample names that don't all share the same token layout can now be tagged correctly. Each row has a checkbox (with select/deselect-all and shift-click range) to choose which rows a paint applies to; a new condition anchors to whatever conditions are already painted on each row, so mixed layouts (e.g. `cellA_dose1` vs `cell_typeA_dose1`) tag without disturbing existing tags.
- Interactive import — clearer steps: the Conditions page is titled "Define experimental conditions systematically" and the Samplesheet page "Define experimental conditions manually", with a preview of the next step beside the Next button.
- Interactive import — gene-name fallback: when no Name column is assigned, the gene label falls back to the UniProt-fetched gene name from the annotation step.
- Gene selector: the protein description (from the UniProt fetch) is shown beside each gene name, and search now also matches a substring of that description (case-insensitive). Custom gene sets are scrollable (8 rows), can be expanded to uncheck member genes, and offer "add current selection"; actions are compact icons with hover tooltips and a two-step confirm on rewrite/delete.
- Dumbbell plot: the selected/hovered gene's name is now bolded, matching the bubble plot.
- Dose-/time-response plots: the new-step and add-plot menus name them correctly ("Dose-response", "Time-response", "Time & Dose-response"), and only offer the axes the upstream data actually has (e.g. no time-response when time isn't an active condition).
- Empty-canvas onboarding: a new project points you to set the project data folder first, then reveals the add-step affordance; the folder chip gets a minimal delete control and a clear call-to-action when no folder is set.

## Fixes

- Interactive import condition assignment: painted conditions no longer disappear when you return to the Conditions page (including after renaming a value on the Samplesheet page), and the "original" value shown on the Samplesheet page is now correct even when sample names follow inconsistent formats. The highlight, the extracted value, and the "original" all derive from the same per-row region, so they can never drift apart.
- The UniProt protein description now shows reliably in the gene selector (previously only surfaced from comparison results).
- The raw-data file selector in the interactive Load tile no longer overflows or gets clipped by a long file name; the file dropdown and Browse button now sit on their own line under the header.
- The first tile dropped on an empty canvas is no longer over-zoomed, and stays where it's placed instead of being auto-recentred.
