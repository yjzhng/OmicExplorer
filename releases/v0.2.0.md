## New features

- **Interactive import wizard** — a guided flow (Columns → Filtering → Conditions → Samplesheet → Metadata) with a clickable progress roadmap and per-step state that persists. Includes a row-**Filtering** stage (drop feature rows by a column's categorical values or a numeric range, with a live removed-rows preview) and bulk value **refactoring** in the samplesheet step.
- **Two-way ANOVA** now accepts **multiple levels per factor** (e.g. drugA, drugB vs DMSO) — each numerator×denominator pair runs as its own 2×2 interaction.
- New **correlation-matrix** plot and a **QC** plot (per-sample intensity / %CV / protein count) for standardized data.
- Fold-change **heatmap** over comparison columns (significant genes only, biclustered) and a **matrix** form of the comparison table (cell = log₂FC).
- **Renamable result tiles** (category / type / name), per-tile run-status indicators, buffering spinners, and paced tile reveals.

## Improvements

- Heatmap groups sample columns by condition (strain → cmpd → dose → time); condition annotation tracks are sized to stay legible.
- Cluster plot (PCA/UMAP/t-SNE) colors dose/time on a sequential Blues/Reds ramp, and only log-transforms data that looks like raw intensity.
- Dose/time-response defaults to the top 10 (ranked by response at the top dose); Bubble defaults to top 20; both use evenly-spaced discrete axes.
- Contrast/compare scatter colors significance groups with the volcano/MA scheme (up / down / none).
- Volcano/MA: always-on centered legend (no hover bounce) plus **GOI** and **Selected** legend groups.
- Canvas: scroll-to-zoom at the cursor over a tile, and smoother tile dragging on large projects.

## Fixes

- Discrete dose/time axes no longer flip to numeric spacing on hover.
- macOS builds are ad-hoc-sealed so Gatekeeper shows the recoverable "unidentified developer" prompt instead of the unescapable "is damaged" one.
